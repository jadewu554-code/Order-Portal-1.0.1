# Order Project

This project is a system individually designed for SuperTac members to introduce each member and to make communication more accessible and efficient for both our group and its members.

---

## Features

- Modern UI/UX design
- Modern Artwork
- Simple and user-friendly interface
- Keyboard shortcut support
- Sound control system
- Input execution system for questions
- Secret answers from input

---

## Technical Details

| Key | Function |
|------|-----------|
| `A` | Toggles the website sound on/off |
| `Enter` | Executes the active input |

- Site is not responsive PC usage only.
- 1.0.1v

---

## Usage

1. Open the website
2. Enter data into the input field
3. Press `Enter` to execute the action
4. Use the `A` key to control the sound
